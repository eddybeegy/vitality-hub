# Settings Documentation

The application provides a comprehensive settings panel to manage user preferences and integrations.

## AI Settings

- **AI Provider**: Select the AI provider (e.g., Gemini, OpenAI, Groq).
- **AI Model**: Select the specific model for the chosen provider.
- **AI Persona**: Choose the AI's personality (Encouraging Coach, Strict Analyst, Data-Driven Scientist, Casual Friend).
- **AI Focus**: Choose the primary goal for the AI (General Health, Fat Loss, Muscle Gain, Body Recomposition, Endurance).
- **AI Hints**: Enter custom instructions to guide the AI.

## Health Settings

- **Health Targets**: Define daily targets for weight, body fat, muscle mass, steps, VO2 max, and calories.
- **Preferred Units**: Choose between metric and imperial units.
- **Timezone**: Set the timezone for accurate daily aggregation of health data.
- **Data Source Modules**: Manage integrations with Withings, Hevy, Cronometer, and Apple Health.
