# Database Structure

The application uses a SQLite database to store user information, health metrics, and AI insights.

## Key Tables

- **users**: Stores user profile data, settings (AI persona, focus, etc.), and integration keys.
- **meal_items**: Stores daily nutrition data (calories, protein, carbs, fat, etc.).
- **ai_insights**: Stores AI-generated insights for nutrition and workouts.
- **chat_history**: Stores chat messages between the user and the AI assistant.
- **metrics**: Stores various health metrics (weight, sleep, heart rate, etc.).
- **workouts**: Stores workout data.
- **routines**: Stores workout routines.
- **exercises**: Stores exercise information.
- **sets**: Stores individual exercise sets.
